# Carom

Carom is a browser-first top-down paddle duel. Curve the ball with paddle motion, bounce it around live rotating blockers, and outscore your opponent in Solo or local Versus.

Install dependencies with `npm ci`, then start development with `npm run dev`. Create a deployable static build with `npm run build`; it writes the site to `dist/`.

Controls: Player one uses **W/S** and player two uses **Up/Down**. In Solo, either pair moves the left paddle. **Enter** or **Space** confirms menus, **P** pauses, **Escape** goes back, and **M** mutes sound.
